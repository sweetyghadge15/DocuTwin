# DocuTwin Sample Data

This directory contains sample text files for testing and demonstrating **DocuTwin — Intelligent Document Similarity & Relationship Analyzer**.

### Files included:
1. **`Research_Paper_A.txt`**: Original research abstract and introduction on Machine Learning in Healthcare and Medical Diagnosis.
2. **`Research_Paper_B.txt`**: Paraphrased version of Paper A using different vocabulary and sentence structures (high semantic similarity, moderate lexical similarity).
3. **`Research_Paper_C.txt`**: Direct copy with minor word substitutions of Paper A (high lexical and high semantic similarity).
4. **`Project_Report.txt`**: Unrelated document discussing Cloud Computing, Microservices, and Infrastructure (low similarity to Papers A, B, and C).
